# OpenClaw Knowledge Vault

## Entry Points
- [[daily/]] — Chronological logs
- [[projects/]] — Project-specific knowledge
- [[tools/]] — Tool documentation (from crawl4ai)

## About This Vault
This vault is the agent's linked knowledge graph (Layer 3 of the 5-layer memory stack).
Every note uses [[wiki-links]] to related notes. No orphan notes allowed.
Synced via obsidian-git to a remote repository.
