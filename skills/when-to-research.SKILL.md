# When to Research

## Trigger
Before starting ANY task.

## Process
1. Assess confidence in approach (0-100%)
2. Spawn Memory Agent: search all 5 layers for relevant context
3. If <30% confidence: STOP. Research first using:
   - NotebookLM for deep cross-source analysis
   - Tavily for current web information
   - crawl4ai for documentation
4. If 30-70% confidence: Quick search, proceed with caution
5. If >70% confidence: Proceed with implementation

## Rules
- Never start coding without at least a quick memory search
- If the task involves a tool you haven't used before, research it first
- If the task involves hardware, check robotics notes in Obsidian
- Log research findings to appropriate memory layers
